# certs/

Место для корневого сертификата Минцифры («Russian Trusted Root CA») — нужен для T-Invest API в Ф1.

В Ф0 каталог пуст. В Ф1 (TASK_F1 §1.2):
1. Скачать сертификат **только** с официального источника (Госуслуги / Минцифры).
2. Положить сюда как `russian_trusted_root_ca.crt`.
3. Записать здесь источник (URL) и **SHA-256 отпечаток**.
4. Раскомментировать блок в `Dockerfile`: копирование в `/usr/local/share/ca-certificates/`,
   проверка отпечатка (`sha256sum -c`, не совпал → сборка падает), `update-ca-certificates`.

Проверку TLS **никогда** не отключать (`verify=False` и аналоги запрещены).
