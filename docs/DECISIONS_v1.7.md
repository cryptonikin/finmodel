## Известные ограничения v1
- id строки = hash(видео + кусок + номер тезиса). При повторном прогоне модель может вернуть другое число тезисов → лишние старые строки останутся. Решение в v2: перед записью удалять строки этого видео.
- Нет повторного запроса при битом JSON — кусок уходит в «Ошибки», перезапуск вручную.
- Узел Safe Execute: имя поля вывода не задокументировано; код читает `stdout`/`output`/`data`.
- Лимит OpenRouter free: ~50 запросов/день (≈2–3 видео по 2 часа).
- Dockerfile `claude-box` не собран в проверочной среде (нет Docker) — проверить при первом `docker compose build`.
