## 2. Кто что видит и куда пишет

| Участник | Читает | Пишет | Секреты |
|---|---|---|---|
| Владелец | всё | ввод в таблицах, `secrets\`, `git push` | все |
| Claude Code (контейнер) | только `code\` | только `code\` + локальный commit | нет |
| finmodel (контейнер) | Таблицы, Т-Банк, Docker secrets | `data\`; в Таблицы — только свои колонки/строки, только в существующие пустые строки | Google, Т |
| Apps Script | Таблицы, MOEX, smart-lab, Финам | свои колонки (SHEETS_INTERFACE §3) | — |
| n8n (транскрибация) | ссылки на видео | `D:\n8n-invest\files` | — |
| GitHub | — | хранит код и документы | нет (gitleaks / detect-secrets) |

## 4. Поток данных Ф1

```
Т-Банк API ──► fetch ──► SQLite (операции, 3 мес) ──► sync: сопоставление с «Журналом»
                                                       ├─ уже есть → пропуск
                                                       ├─ сомнительно → отчёт владельцу
                                                       └─ новое → бэкап листа → запись в пустые строки
                                    cleanup: удалить локально старше 3,5 мес ◄──┘
```

## 5. Перенос на VPS (Ф4)
- Переезжают: `code\` (git clone), `secrets\` (вручную, защищённо), `data\` (по желанию); тот же compose; SQLite → Postgres.
- Остаются на ноутбуке: claude-box, n8n (транскрибация).

## 6. «Бюджет и инвестиции - ai» — пока вручную (решение 06.11.2026, пересмотр после Ф1б)
- T-Invest API отдаёт **только брокерские счета**; операции по картам и текущим счетам он не даёт
  (публичного API для личного банка у Т-Банка, насколько известно, нет — проверить при необходимости).
  Сбер, Альфа, наличные, крипта, вклады — тоже вручную.
- Сейчас автоматизация бюджета дала бы мало (месячное обновление ≈ 15 мин) при риске записи в семейный лист.
- План: (Б1) после Ф1б — предлагать **срез портфеля Т по классам** для месячного листа (только как значения для сверки,
  не перезаписывая ввод); (Б2) по желанию — импорт банковских выписок CSV с **локальными** правилами категорий
  (без LLM: это личные данные).
